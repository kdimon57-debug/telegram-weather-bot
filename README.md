# Погода в Telegram

Бот ежедневно отправляет температуру на улице, скорость ветра, погодные условия и прогноз общего количества осадков за текущий день. Время рассылки задаётся в формате `ЧЧ:ММ` по часовому поясу выбранного города. Город и время можно менять по отдельности. Для одноимённых городов бот предлагает выбрать нужный вариант из списка.

После настройки нажмите «Узнать погоду сейчас», чтобы получить свежую сводку для сохранённого города. Ежедневная рассылка продолжится по вашему расписанию.

## Запуск на Windows

1. Убедитесь, что в PowerShell работает `node --version`. Подходит Node.js 22 начиная с 22.13.0 или Node.js 24 и новее. [Скачать Node.js](https://nodejs.org/en/download)
2. Откройте @BotFather в Telegram, отправьте `/newbot` и укажите имя и username бота. Если бот уже создан, возьмите его токен в BotFather. [Открыть @BotFather](https://t.me/BotFather)
3. В PowerShell из папки проекта выполните команды ниже. Первая команда нужна при первоначальной настройке.

   ```powershell
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   notepad .env
   ```

4. Вставьте токен после знака `=` в строке `TELEGRAM_BOT_TOKEN=` и сохраните файл. Храните токен в локальном `.env`.
5. Запустите бота.

   ```powershell
   node --env-file=.env src/main.js
   ```

6. Откройте ссылку, которую бот выведет в терминале. Нажмите «Старт», выберите «Найти город», введите город и задайте время на ближайшие 2–3 минуты для проверки. Если бот предложит несколько вариантов, отправьте номер нужного города.

Для ежедневной отправки процесс должен работать постоянно. Для пробного запуска оставьте окно PowerShell открытым, а компьютер включённым и подключённым к интернету. Для круглосуточной работы запустите ту же команду на постоянно работающем компьютере или сервере. Используйте один экземпляр бота на токен.

Настройки пользователей и даты отправки хранятся в `data/weather.sqlite`. Если процесс пропустил время отправки и запустился в тот же день по часовому поясу города, он отправит сводку после запуска.

Прогноз берётся из бесплатного API Open-Meteo для некоммерческого использования. [Условия Open-Meteo](https://open-meteo.com/en/terms)
